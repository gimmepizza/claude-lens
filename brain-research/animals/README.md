# Comparative Neuroscience — The Animal Brains

A companion to the [human-brain reference](../README.md): in-depth, cited
deep-dives on **18 of the animals whose nervous systems have been studied most
extensively** — the model organisms that built modern neuroscience, and the
independently-evolved minds (cephalopods, corvids, insects) that show what a brain
*else* can be.

Each document is web-researched, cross-verified, flags contested claims explicitly,
and ends with a linked **Sources** section. Start with the
**[Comparative Overview & Synthesis](00-comparative-synthesis.md)** for the big
picture — why we study animal brains, the seven cross-cutting lessons, and what each
model uniquely gave us — then dive into any species below.

> **[▶ Comparative Overview & Synthesis](00-comparative-synthesis.md)** — read this first.
